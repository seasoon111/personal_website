# 个人网站 · 需求与方案确认文档

> 版本：v1.0（待确认）
> 日期：2026-11-04
> 技术栈：Go + Vue3 + MySQL
> 状态：**未开工，等待确认**

---

## 一、项目目标

做一个**自己长期维护**的个人网站，用来沉淀文章、展示项目、记录日常动态、介绍自己。
首版先在本机跑通，后续整体迁移到阿里云服务器，架构保持同构（本地怎么跑，线上就怎么跑）。

---

## 三、功能范围（首版）

### 3.1 前台页面

| 页面 | 路由 | 说明 |
|------|------|------|
| 首页 | `/` | 头像+一句话介绍 → 精选项目（3~4 个）→ 最新文章（5 篇）→ 最新动态（3~6 条）→ 页脚 |
| 文章列表 | `/articles` | 分页列表，支持按分类、标签筛选；顶部展示分类导航 |
| 文章详情 | `/articles/:slug` | Markdown 渲染、目录（TOC）、上一篇/下一篇、发布时间/分类/标签 |
| 归档 | `/archives` | 按年份分组的文章时间线 |
| 项目列表 | `/projects` | 卡片网格，封面 + 标题 + 技术栈标签 |
| 项目详情 | `/projects/:slug` | 封面大图、Markdown 正文、技术栈、仓库/演示链接 |
| 动态 | `/moments` | 时间线，每条 = 文字 + 最多 9 图（九宫格），支持点击看大图 |
| 关于我 | `/about` | 头像、自我介绍、技能标签、经历时间线、社交链接、联系表单 |
| 404 | `/:pathMatch(.*)*` | 手账风插画 + 返回首页 |

**全局**：响应式（≥1280 / 768~1279 / <768 三档）、中英切换按钮（右上角）、滚动淡入动画、图片懒加载。

### 3.2 后台管理

| 模块 | 能力 |
|------|------|
| 登录 | 账号 + 密码，JWT（有效期 7 天），登录失败限流（5 次/分钟/IP） |
| 仪表盘 | 文章数、项目数、动态数、图片数、未读留言数、最近 5 篇草稿 |
| 文章管理 | 列表（筛选状态/分类/关键词）、新建/编辑（Markdown 编辑器 + 实时预览）、保存草稿、发布/下架、置顶、删除、封面图选择 |
| 分类管理 | 增删改、排序、slug |
| 标签管理 | 增删改、slug、使用次数 |
| 项目管理 | 增删改、封面、技术栈标签、仓库/演示链接、排序、上下架 |
| 动态管理 | 发布文字 + 最多 9 图、删除、编辑、时间线排序 |
| 关于我 | 编辑头像、自我介绍（Markdown）、技能标签、经历时间线（可增删条目）、社交链接（可增删条目） |
| 图片库 | 上传（拖拽/多选）、列表、复制 URL、删除（被引用时提示） |
| 留言 | 查看联系表单提交、标记已读、删除 |
| 账号 | 修改密码 |

**后台 UI**：左侧导航 + 右侧内容区，同一套手账风（米色底、陶土红强调色），不追求管理系统的「冷感」。

## 四、技术方案

### 4.1 后端（Go）

```
Gin（HTTP 框架）
GORM（ORM，AutoMigrate + 手写索引）
MySQL 8（utf8mb4）
JWT（github.com/golang-jwt/jwt/v5）
bcrypt（密码哈希）
go-playground/validator（参数校验）
zap 或 log/slog（日志，用标准库 slog 即可，少一个依赖）
```

**分层**：`handler → service → repository → model`，DTO 与 model 分离，统一响应结构：

```json
{ "code": 0, "message": "ok", "data": {} }
```

**存储抽象**：

```go
type Storage interface {
    Save(ctx, file, filename) (url string, err error)
    Delete(ctx, url string) error
    URL(path string) string
}
// 首版实现：LocalStorage（./uploads 目录，按 年/月 分目录）
// 预留：OSSStorage（阿里云 OSS）
```

**安全**：上传限制 10MB、仅 jpg/png/webp/gif；后台接口全部走 JWT 中间件；密码 bcrypt cost 10；CORS 只放行本地与未来域名。

### 4.2 前端（Vue3）

```
Vue 3.4 + TypeScript
Vite 5
Vue Router 4（history 模式）
Pinia（只存登录态 + 语言偏好）
Tailwind CSS 3（自定义 design token）
vue-i18n 9（zh-CN / en-US，仅界面文案）
markdown-it + highlight.js + @tailwindcss/typography（文章渲染）
md-editor-v3（后台 Markdown 编辑器，含预览与代码高亮）
axios（统一拦截器：加 token、401 跳登录、错误提示）
```

**目录结构（frontend/src）**：

```
api/          按模块拆分的请求函数
assets/       字体、插画 svg、纸纹
components/   通用组件（AppHeader/AppFooter/ArticleCard/MomentCard/ImageGrid/Tag/...）
composables/  usePagination、useI18n、useScrollReveal
layouts/      DefaultLayout（前台）、AdminLayout（后台）
locales/      zh-CN.ts / en-US.ts
pages/        Home/Articles/ArticleDetail/Archives/Projects/ProjectDetail/Moments/About/NotFound
pages/admin/  Login/Dashboard/Articles/ArticleEdit/Categories/Tags/Projects/Moments/About/Images/Messages
router/       路由 + 守卫（/admin 需登录）
stores/       auth.ts、ui.ts
styles/       main.css（tailwind + 自定义类）
types/        接口类型定义
utils/        日期、slug、图片 URL 拼接
```

### 4.3 视觉规范（手账风）

| Token | 值 | 用途 |
|-------|-----|------|
| `--paper` | `#FAF5EC` | 页面底色（米色纸） |
| `--paper-deep` | `#F1E7D6` | 卡片/分区底 |
| `--ink` | `#3B332C` | 正文墨色 |
| `--ink-soft` | `#7A6E62` | 次要文字 |
| `--terracotta` | `#C4633F` | 主强调色（陶土红） |
| `--terracotta-soft` | `#E8B39C` | 悬停/标签底 |
| `--sage` | `#8A9A7B` | 辅助色（少量点缀） |
| `--line` | `#E3D6C2` | 分割线/边框 |

- **字体**：标题用「霞鹜文楷 LXGW WenKai」（开源，手写感，CDN 或本地 woff2）；正文用系统无衬线（PingFang / Microsoft YaHei / system-ui）；代码用 JetBrains Mono。
- **手账元素**：纸纹噪点背景（SVG，透明度 3%）、胶带贴纸（CSS 伪元素，倾斜 2°）、虚线分割线、卡片轻微旋转（0.5°~1°，hover 回正）、手写体日期、圆形印章式标签。
- **插画**：空状态/404/联系成功用 unDraw 或 Storyset 免费插画，统一改色为陶土红+米色系；本地存放，不引外链。
- **动效**：滚动淡入（IntersectionObserver，位移 12px + 透明度），时长 400ms；尊重 `prefers-reduced-motion`。

## 五、数据库设计

> 库名 `personal_website`，字符集 `utf8mb4`，排序 `utf8mb4_0900_ai_ci`。所有表带 `created_at`、`updated_at`；软删除仅文章、项目、动态需要。

| 表 | 关键字段 | 说明 |
|----|----------|------|
| `users` | id, username(uniq), password_hash | 单管理员，初始化时种子写入 |
| `categories` | id, name, slug(uniq), sort | 文章分类 |
| `tags` | id, name, slug(uniq) | 标签 |
| `articles` | id, title, slug(uniq), summary, content_md, content_html, cover_url, category_id, status(draft/published), is_pinned, published_at, deleted_at | 文章 |
| `article_tags` | article_id, tag_id (联合主键) | 多对多 |
| `projects` | id, title, slug(uniq), summary, content_md, content_html, cover_url, tech_stack(JSON), repo_url, demo_url, sort, status, deleted_at | 项目 |
| `moments` | id, content(text), is_public, deleted_at | 动态 |
| `moment_images` | id, moment_id, image_id, sort | 动态配图（≤9） |
| `images` | id, filename, original_name, path, url, mime, size, width, height | 图片库 |
| `about_profile` | id(=1), avatar_url, intro_md, skills(JSON), timeline(JSON), socials(JSON) | 单例表，关于我 |
| `contact_messages` | id, name, email, subject, content, is_read | 联系表单 |

**索引**：articles(status, published_at)、articles(slug)、articles(category_id)、moments(created_at)、images(created_at)。

**种子数据**：1 个管理员、3 个分类、6 个标签、3 篇示例文章、3 个项目、5 条动态、1 份关于我。

## 十、维护约定（长期）

- **Git**：`main` 保持可运行；功能在 `feat/xxx` 分支开发；提交信息用 `feat: / fix: / docs: / chore:` 前缀。

## 十一、风险与取舍

| 风险 | 处理 |
|------|------|
| 纯 SPA 不利 SEO | 已确认接受；后续若要，可加预渲染（vite-plugin-prerender）而不改架构 |
| 本机 MySQL 密码/权限不明 | 开工前先跑连通性检查，失败则给排查步骤 |
| 图片存本地，服务器迁移要带走 | 备份脚本包含 `uploads/`；存储层抽象好，换 OSS 只改实现 |
| 手账风容易「花」 | 装饰元素控制在背景/分割线/标签，正文区域保持高可读性 |
| 中英双语只做 UI | 文章不翻译，避免内容维护成本翻倍；i18n 结构保留，未来可扩 |
